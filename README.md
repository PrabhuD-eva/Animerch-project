\# AnimeMerch - Anime Merchandise Store



A full-stack e-commerce website for anime merchandise built with Django.



\## Features

\- 🏠 Home page with featured products

\- 🛍️ Product listing with categories

\- 🛒 Shopping cart functionality

\- 👤 User authentication (Login/Register)

\- 📦 Order management

\- 👤 User profile

\- ℹ️ About Us page

\- 📞 Contact Us page



\## Pages

\- Home

\- Products

\- About Us

\- Contact Us

\- Cart

\- Checkout

\- Order History

\- Profile Settings

\- Login

\- Register



\## Technologies Used

\- Django 6.0.3

\- Bootstrap 5

\- SQLite3

\- HTML/CSS

\- JavaScript/jQuery
